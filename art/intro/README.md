# Opening cinematic artwork

`opening.png` is a 2×2 atlas generated with the built-in image tool on 14 September 2026. The exact final prompt is in `prompt.txt`. The selected PNG is embedded byte-for-byte in the offline HTML.

Shots: Mara's incoming call and family photo; Alex approaching Relay Station 6; the abandoned maintenance checkpoint and flooded stairs; the public-address speaker. The final title shot uses the existing Alex key art from `art/presentation/hero.png`.

The game animates these illustrations with camera movement, fades, letterboxing, timed captions and synthesized sound. It is a 32-second in-engine cinematic, not a streamed video or recorded voice performance. No new external playback dependencies are required.
