# Zombie artwork — v0.6

Generated with the built-in image-generation tool on September 13, 2026. Higgsfield was not connected or used. The original PNGs are retained here; identical PNG bytes are embedded in dist/index.html, so offline play needs no asset folder. Each image is a 1254 × 1254 RGBA atlas. Quadrants: front, left profile, rear, right profile.

These are directional sprites drawn on animated, lit surfaces in the 3D world, not fully sculpted character meshes. The four-view transitions and flattened corpse artwork are intentional retro-FPS presentation limits. The canvas fallback uses the same atlas. The previous procedural models remain a loading/failure fallback.
