# The Long Night story artwork

`scenes.png` is an original four-panel cinematic atlas generated with the built-in image-generation tool for v0.10.0. The exact generation prompt is in `prompt.txt`.

Panels: municipal archive/underpass, Inez Rook at Meridian, the Alder House common room, and Mara at the daylight gate. The selected PNG is embedded byte-for-byte in `dist/index.html`. The game does not download it at runtime. Chapter arrival cards and the three-page epilogue reuse these illustrations.

The artwork is illustrative. Gameplay remains the existing 3D environment and sprite-based combat, with no external video or voice-acting dependency.
